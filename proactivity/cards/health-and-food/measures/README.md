# Health measures

A measurement over time, with dates and units.

| Situation | When it fits | File |

| Report for an appointment | Readings are gathered into one file to take to a doctor. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/report-for-an-appointment.html` |
| Sleep over a week | Seven nights of sleep with the average and the outlier. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/sleep-over-a-week.html` |
| Goal reached | A measure reached the target the user set for themselves. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/goal-reached.html` |
| Steps so far today | A count against the user's own daily goal, part way through the day. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/steps-so-far-today.html` |

| A child's height | A family member's measurement is logged and set against the last one. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/a-child-s-height.html` |
| Measuring streak | The user has kept up a measuring habit without a miss. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/measuring-streak.html` |
| Monthly summary | The month's averages for each measure the user tracks. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/monthly-summary.html` |

| Goal set | The user named a target and a date, and tracking starts now. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/goal-set.html` |
| Year in view | Twelve months of one measure, to see the shape of the year. | `/opt/muse/assets/proactivity/cards/health-and-food/measures/year-in-view.html` |
