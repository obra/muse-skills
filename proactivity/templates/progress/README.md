# Progress comparisons

Tools: `widget.create_html_widget` or `widget.create_html_file_widget`.

Use [before-after.html](before-after.html) for a meaningful change in a workout, project or personal goal.

Compare like with like and keep dates, units and the measured scope visible. Do not infer health improvement, causation or financial returns from a partial log. A comparison may be encouraging without assigning a score or creating a new obligation. State material gaps plainly. Use the user’s own goal and preferred tone. An unchanged or incomplete log is not a reason to ask again.

Read the [library guide](../README.md) and adapt the closest reference freely. Use the user’s language and taste, replace and HTML-escape all placeholders, and remove anything irrelevant. Create a bespoke layout when this one does not fit. Follow the tool’s current authoring rules and keep exact presentation references.

Installed references: `/opt/muse/assets/proactivity/templates/progress/`.
